Avatar from poketeamcalculatorfrontend. Use via `window.Contrataque.Avatar` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<ContrataqueProvider>` (full provider chain in README.md — components read theme/i18n from that context).

## Props

```ts
interface AvatarProps {
/** Nombre del Pokémon; se muestra su inicial. */ name: string; /** Diámetro en px (32 lista, 44–48 tarjeta, 96 destacado). */ size?: number; /** 'avatar-accent' = fondo naranja de acento. */ className?: string;
}
```
